# VOC M2 注意力基线矩阵总结（修复后，bs4）

## 设置

- 数据集：VOC 07+12 full（无泄漏）
- 训练：VOC 2012 train，验证：VOC 2012 val
- 模型：MobileNet V3 Large 320 FPN / ResNet50 FPN
- 方法：FcaNet、ECA 注意力基线（对比 M1 的 baseline 与 FPN-SM）
- 种子：42、2024、999
- batch size：MobileNet bs32，ResNet bs4
- resize：MobileNet 320×320，ResNet 800/1333

## 结果（AP50 / AP75，mean ± std）

| 模型     | 方法       | AP50          | AP75          | 相对 baseline ΔAP50 | 相对 baseline ΔAP75 |
|----------|------------|---------------|---------------|----------------------|----------------------|
| MobileNet| baseline   | 0.6806 ± 0.0930 | 0.4639 ± 0.1238 | —                    | —                    |
| MobileNet| FcaNet     | 0.5705 ± 0.0053 | 0.3220 ± 0.0061 | **−0.1101**          | **−0.1419**          |
| MobileNet| ECA        | 0.5665 ± 0.0041 | 0.3205 ± 0.0097 | **−0.1141**          | **−0.1434**          |
| MobileNet| FPN-SM     | 0.7201 ± 0.0060 | 0.5183 ± 0.0046 | **+0.0395**          | **+0.0544**          |
| ResNet50 | baseline   | 0.7913 ± 0.0134 | 0.5514 ± 0.0146 | —                    | —                    |
| ResNet50 | FcaNet     | 0.6395 ± 0.0217 | 0.3773 ± 0.0255 | **−0.1518**          | **−0.1741**          |
| ResNet50 | ECA        | 0.6334 ± 0.0340 | 0.3739 ± 0.0342 | **−0.1580**          | **−0.1775**          |
| ResNet50 | FPN-SM     | 0.8406 ± 0.0188 | 0.6221 ± 0.0133 | **+0.0492**          | **+0.0707**          |

## 结论

1. **FcaNet / ECA 注意力基线在两种骨干上均显著低于 baseline**，AP50 下降约 0.11–0.16，AP75 下降约 0.14–0.18。
2. **FPN-SM 在两种骨干上均稳定提升 baseline**，MobileNet +0.0395 AP50，ResNet50 +0.0492 AP50。
3. MobileNet baseline 方差较大（seed 42 异常低：AP50=0.5732），主要由该次训练异常导致；建议后续对该种子复现或排查。
4. 所有 12 个 run 均正常完成，无 NaN / OOM / failed_nan。
