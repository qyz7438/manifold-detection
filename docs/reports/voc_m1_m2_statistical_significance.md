# VOC M1/M2 统计显著性检验（S1）

## 方法

- 配对样本 t 检验（paired t-test），n = 3 seeds（42、2024、999）
- 对比指标：AP50、AP75
- 显著性水平：p < 0.05（标记 *）

## 结果

| 模型     | 方法   | AP50 Δ   | AP50 p  | AP75 Δ   | AP75 p  | 显著？ |
|----------|--------|----------|---------|----------|---------|--------|
| MobileNet| FPN-SM | +0.0395  | 0.5193  | +0.0544  | 0.5206  | 否     |
| MobileNet| FcaNet | −0.1101  | 0.1628  | −0.1419  | 0.1727  | 否     |
| MobileNet| ECA    | −0.1141  | 0.1563  | −0.1434  | 0.1697  | 否     |
| ResNet50 | FPN-SM | +0.0492  | 0.0219  | +0.0707  | 0.0073  | 是     |
| ResNet50 | FcaNet | −0.1518  | 0.0057  | −0.1741  | 0.0013  | 是     |
| ResNet50 | ECA    | −0.1580  | 0.0065  | −0.1775  | 0.0043  | 是     |

## 结论

- **ResNet50 + FPN-SM**：AP50 与 AP75 的提升均统计显著，是矩阵中唯一显著正向方法。
- **ResNet50 + FcaNet / ECA**：显著低于 baseline，确认这些方法在当前配置下有害。
- **MobileNet + FPN-SM**：均值提升，但因 seed 42 异常低导致方差大，p 不显著。
- **MobileNet + FcaNet / ECA**：均值下降，但 p 不显著（同样受高方差影响）。

## 建议

- 复现 MobileNet baseline seed 42，排除异常值后再评估 MobileNet 上的显著性。
- 后续消融实验（A2–A10）优先在 ResNet50 上进行，统计功效更高。
